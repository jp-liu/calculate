# calculate

一个零依赖的纯前端计算器（单文件 HTML + 原生 JS）。

## 运行
直接用浏览器打开 `index.html`。

## 功能
- 基础四则运算：加、减、乘、除（标准运算符优先级：先乘除后加减，幂运算最高，同级左结合）
- 等号求值、连续等号（重复最后一次运算）、正负号切换、百分号
- 表达式行实时显示完整输入（如 `12 + 3 × 4`）
- 普通 / 科学计算器模式切换（切换时当前计算状态完整保留）
- 科学模式：sin/cos/tan、log/ln、x^y 幂运算、√ 平方根、π 常量、阶乘 !
- 角度/弧度：科学模式提供 DEG/RAD 切换，默认 DEG（角度制，如 sin30° = 0.5）
